《港硕这一年》 v1.0.0
Unity 2022.3.62f3c1 / C# / uGUI + TextMeshPro

开始玩
1. 在 macOS 双击「开始游戏.command」，启动 Build/macOS/港硕这一年.app。
2. 也可双击「浏览器试玩.command」，在 http://127.0.0.1:8916 游玩真正的 Unity WebGL 构建。
   保持终端打开；关闭浏览器后下次仍用相同端口，浏览器存档跟随该地址。
3. 新游戏 → 简短引导 → 开学事件 → 每回合排满四格 → 确认 → 事件 → 回合总结。
   可以通过行动槽上的箭头调整先后顺序，用「改」替换，用「×」删除。
4. 原生版与浏览器版各自保存进度，不共用存档。重新开始前会确认覆盖。

完整内容
26 个两周回合，10 类行动，4 门分学期开放的课程，29 个事件条目。
5 个主结局，多个 offer 自主选择，2 种可叠加荣誉。没有恋爱攻略。
所有界面和存档都在本地运行，不依赖账号、API 或联网服务。

课程
研究方法与学术写作：第 1 回合开课，作业 6、项目 12 回合截止。
数据分析与实践：第 1 回合开课，作业 8、项目 13 回合截止。
城市与社会观察：第 14 回合开课，作业 18、项目 24 回合截止。
专业综合项目：第 14 回合开课，作业 20、项目 25 回合截止。
成绩 = 学习进度×40% + 已交作业质量×25% + 已交项目质量×35%。
GPA：93/85/80/75/70/65/60/50 分对应 4.0/3.7/3.3/3.0/2.7/2.3/2.0/1.0，50 以下为 0。
截止日有进度的任务自动提交；零进度任务保留补交入口。补交质量打 75% 折扣。
可在课程页提前提交；提交后不能再加工该任务，学习进度仍可以继续增加。
毕业需要四课均≥50、8 项任务均已交、最终 GPA≥2.00，并提交毕业申请。

平衡与后果
初始资金 $12000，每回合生活费 $450。学费和基础住宿费已付。
压力≥70/90，属性及课业增长乘以 70%/50%；同一回合重复同类行动再乘 100%/80%/60%/45%。
属性达到 70 后，行动带来的该项属性增量按 40% 计。课程进度不受此软上限影响。
休息与休闲可减压；休息排在学习前会影响学习时的效率。现金收入和减压不打折。
现金不足自动使用无息应急生活金；后续回合结算用多于 $300 的余额还款。
压力最多 100，资金或逾期都不会让游戏卡住。未达毕业条件会给出延期原因。

机会与结局
科研：学业≥24，且有导师联系或 2 次校园活动。
实习：职业≥28，且面试通过或 3 次求职准备。
工作/博士申请：第 16—24 回合，在目标页投递，每方向限一次，材料费 $150、压力 +6。
两回合后按当时预计课程 GPA 审核，收到条件 offer 后，还必须满足最终毕业条件。
留港：职业≥55、适应≥40、实习≥2，回复时预计 GPA≥2.70。
内地：职业≥50、求职准备≥3，回复时预计 GPA≥2.30。
博士：科研≥60、学业≥50、科研≥6、导师联系，回复时预计 GPA≥3.00。
探索：顺利毕业后始终可选，也可主动放弃已收到的其他机会。
延期：任意毕业条件不达标，或最后主动撤回毕业申请。
奖学金：主动申请、最终 GPA≥3.60、学业≥65、顺利毕业。
优秀毕业表现：GPA≥3.60、四课各≥80、科研或实习≥4、顺利毕业。
游戏内条件为玩法设计，不代表真实大学、奖学金、签证或招聘政策。

继续开发
在 Unity Hub 用 Unity 2022.3 LTS 打开本目录，打开 Assets/Scenes/HarbourYear.unity 后按 Play。
入口 YearGame.cs 自动创建界面，YearModel.cs 为纯 C# 规则，YearEvents.cs 为事件与选项。
YearSave.cs 使用 PlayerPrefs JSON + 一份备份，保存回合、日程、未选事件、总结、申请和结局。
游戏菜单「港硕这一年」提供准备场景/字体、构建 macOS、构建 WebGL。
自动化构建建议先运行 ulimit -n 8192，避免本机 Unity/Mono 文件描述符上限触发崩溃。
Tools/test-rules.sh 可独立运行纯规则检查，不必打开编辑器。
Assets/Editor/YearSmoke.cs 覆盖真实 EventSystem 射线、按钮路径、文本溢出和 JSON 存档。
docs/paths 提供由规则测试实际运行出来的 26 回合路线，可用于复核所有结局可达性。
